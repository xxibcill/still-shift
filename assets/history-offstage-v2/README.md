# Original History Offstage motion assets

Three images made with Codex's built-in image generation for the six-preset proof:

- `landscape.png`: a continuous field background.
- `objects-v1.png`: six illustrated objects on transparent alpha, reused across all six scenes.
- `bowl-states.png`: registered empty/filled bowl states, derived from the new object kit.

[Exact executed prompts](./prompts.md) and [lineage, checksums, dimensions, reuse, and cost notes](./provenance.json) accompany the source pixels. These are original schematic illustrations, not historical evidence or approved episode replacements. The 43 retired inputs remain retired.

The source PNGs are unmodified copies of the generated outputs. The compositor samples atlas rectangles defined in `scripts/create-illustrated-demos.ts`; no image editor or segmentation service is required to reproduce these six fixtures. Both atlases have genuine alpha transparency. Cropping and state alignment were inspected against the actual renders.

Preparation time and provider billing were not separately measured. The recorded render timings exclude asset generation, preparation, QA, and revision. End-to-end economics remain unproven.
