# v0.7 preview/export parity evidence

Five original CC0 SVG/depth pairs cover portrait, environment, architecture, illustration, and difficult edges. The test opens each pair in the browser lab, uses its resolved scene without changing camera parameters, and exports the same scene through the PNG and JPEG pipes. It captures preview and decoded MP4 frames at indices 0, 75, and 149 of a 150-frame scene, then compares RGB color and edge differences at 64×36. A saved, compressed preview baseline checks future changes to the shared camera and shader path. A variance beyond tolerance emits `PREVIEW_EXPORT_VARIANCE` in the test result.

On 2026-09-25, after merging the v0.6 changes from `main` and refreshing the baseline, `pnpm test:golden` passed 30 preview/export comparisons across all five scenes. All five used depth mode. The maximum normalized mean RGB difference was 0.0152, maximum edge difference 0.0077, and maximum channel-mean difference 0.0162. The tolerance is 0.03, 0.05, and 0.025 respectively. Unit checks cover color inversion, spatial mirroring, and frozen or reversed frame motion. The test records Chromium 151.0.7922.34, SwiftShader, renderer `preview-render-0.5.0`, shader `depth-plane-0.5.0`, and FFmpeg 8.0.1 with the baseline.

These fixtures test semantics and regressions, not editorial quality on real footage. The private candidate corpus is still awaiting human approval, so parity on the frozen corpus remains open. The single real-still JPEG/PNG comparison measured mean SSIM 0.993 in v0.6; wider real-image JPEG review remains a v0.10 evaluation item.
