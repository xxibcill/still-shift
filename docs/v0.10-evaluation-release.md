## Reproduce the evaluation

Use an approved `frozen` corpus for a release decision. An incomplete private candidate may be examined with `--allow-candidate`; its outputs and ratings are explicitly labeled as candidate evidence.

```bash
pnpm evaluation:prepare --corpus /path/to/private-corpus.json \
  --output /tmp/still-shift-evaluation.jsonl --allow-candidate

STILL_SHIFT_FRAME_TRANSPORT=jpeg_pipe pnpm still-shift batch --manifest /tmp/still-shift-evaluation.jsonl \
  --output-dir /tmp/still-shift-evaluation --concurrency 2

STILL_SHIFT_FRAME_TRANSPORT=jpeg_pipe pnpm still-shift batch --manifest /tmp/still-shift-evaluation.jsonl \
  --output-dir /tmp/still-shift-evaluation --concurrency 2

pnpm evaluation:baselines --corpus /path/to/private-corpus.json \
  --output-dir /tmp/still-shift-baselines

pnpm evaluation:gallery --corpus /path/to/private-corpus.json \
  --results /tmp/still-shift-evaluation/batch-results.jsonl \
  --baselines-dir /tmp/still-shift-baselines \
  --output /tmp/still-shift-evaluation/gallery/index.html

pnpm evaluation:assemble --timeline /path/to/proof-timeline.json \
  --corpus /path/to/private-corpus.json \
  --results /tmp/still-shift-evaluation/batch-results.jsonl \
  --narration /path/to/narration.mp3 \
  --output /tmp/still-shift-evaluation/assembled-explainer.mp4

pnpm evaluation:report --corpus /path/to/private-corpus.json \
  --results /tmp/still-shift-evaluation/batch-results.jsonl \
  --assembly /tmp/still-shift-evaluation/assembled-explainer.mp4.assembly.json \
  --output /tmp/still-shift-evaluation/evaluation-report.md
```

The first batch pass renders the clips. The second verifies every checkpoint and preserves the first full-run timing in `batch-runs.jsonl`. A checkpoint retry does not measure determinism. For that gate, run the same manifest in a separate output directory without reused clips and pass its results to `evaluation:report --determinism-results /path/to/independent/batch-results.jsonl`. `evaluation:prepare` checks each source hash and dimensions and emits one request for each of the three presets at standard intensity. The gallery places source, depth, clip posters, scene risk, warnings, timings, and baseline videos together. Reviewers rate edge artifacts, deformation, borders, depth order, motion fit, editorial usability, and manual-repair need; **Download ratings JSON** exports the ratings from local browser storage. Pass the downloaded file with `--ratings` to `evaluation:report`.

New renders record archived depth-preparation time in each result, including cache hits. The report reads this public metric and model provenance from result records; rerender older clips that lack the archived preparation metric before using a cost gate.

For a cost scenario, the report also accepts `--compute-usd-per-hour`, `--compute-price-source`, `--video-baseline-usd-per-minute`, `--video-baseline-name`, `--video-baseline-source`, and `--operator-minutes`. A worker price without a source produces a **scenario**, not a passed cost gate. These inputs must reflect the selected deployment and workflow before the cost gate is judged. As an illustrative public price, Google's [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing) lists Veo 3.1 Fast with audio at **$0.12 per generated second for 1080p**, or **$7.20 per minute** as of 2026-09-24. This is a price reference, not a quality or workflow equivalent and not the selected user baseline.

For the final decision run, provide the independent rerender results, complete `--ratings`, `--preview-export-accepted yes|no` with `--preview-export-evidence`, `--editorial-accepted yes|no`, `--operator-minutes`, and selected worker and video baseline prices with their sources. Once every gate is measured on an approved frozen corpus, record `--decision go|conditional-go-layered|conditional-go-2d|no-go` with `--decision-reviewer` and `--decision-rationale`. A `go` decision requires every gate to pass; the other outcomes require an explicit rationale.

The independent-render determinism comparison checks each MP4 checksum, actual frame count and duration, and decoded frames at the start, midpoint, and end when encoded bytes differ. The gallery stores and exports ratings against both the corpus checksum and the exact batch artifact set. Re-export ratings after rerendering any clip. The assembly metadata records the corpus revision, selected clip checksums, and final MP4 checksum. The report verifies those identities and probes the assembled video before treating it as editorial evidence. Regenerate older private assembly metadata with this release before using it in a gate report.

## Local candidate run

On 2026-09-24, the unapproved private candidate contained 43 unique stills spanning all seven required categories: 28 from a History Offstage S01E01 proof and 15 commercial photographic stills. Their exact source bytes are identified by the candidate manifest SHA-256 `b9d208dd214b951d4fe140788300897040696d3bb135a0bfb68f067795f65ce7`. No source, rendered media, or private path is committed.

The PNG reference run produced 129/129 valid five-second clips, with 12 clips carrying safety warnings, in 826.8 seconds at concurrency two. Its aggregate throughput was 0.78× real time, below the 1× target. A 30-clip JPEG sample finished in 108.6 seconds (1.38× aggregate real time). The full candidate evaluation explicitly selected the 95%-quality JPEG pipe and produced 129/129 valid clips, again with 12 warning-bearing clips and no failures or 2D fallbacks, in 521.9 seconds at concurrency two: **1.24× aggregate real time on the selected local worker**. All 129 JPEG outputs passed checksum-verified retry in 0.47 seconds. Matched PNG/JPEG clips scored SSIM 0.993 for an illustration, 0.991 for a photographic portrait, and 0.992 for a difficult-edge illustration. Five golden scenes also pass 30 preview/export comparisons with both transports.

A narrated technical assembly from 28 History Offstage states was encoded from the final JPEG clips at 1280×720, 24 FPS, with 11,475 exact frames and 478.125 seconds duration. It uses the existing proof timeline and narration and cycles the three presets within each state. The MP4 has H.264 video and AAC audio. Its editorial quality and repetitiveness require human review.

The candidate gate report measures 43 archived cold-depth preparations at 75.8 seconds total, 129 warm-cache renders at 521.9 seconds, and the 84 selected clips plus 28 source preparations used by the narrated assembly. At a **hypothetical** $5/hour worker rate, the selected work costs about $0.566, or $0.071 per finished assembled minute. Against the illustrative Veo price above, this is a 99.0% render-cost reduction. These figures exclude source-image creation, storage, retries, and operator labor, and no cloud worker with equivalent performance has been priced or tested. The cost gate remains pending.
