# Vertical video safe zones: published guidance

- **Research date:** 2026-09-27
- **Plan:** [VV0 in the vertical video plan](vertical-video-plan.md#vv0--research-and-owner-decisions)
- **Scope:** Platform interface overlays and placement of authored text or focal subjects in 9:16 video. The findings below support the owner policy recorded on 2026-09-28; they do not define a numeric organic-Shorts `vertical.safeZones` default.

## Google Ads vertical diagram: numeric reference

The red _allowed_ rectangle in [Google's vertical video-ad diagram](https://support.google.com/google-ads/answer/13547298?hl=en#SafeZones) is labeled with the following margins for a 1080×1920 frame. These are platform-published **ad** measurements, not measurements of organic Shorts:

| Edge outside the red area | Pixels | Share of that frame dimension |
| ------------------------- | -----: | ----------------------------: |
| Left                      |     48 |                 4.4% of width |
| Right                     |    192 |                17.8% of width |
| Top                       |    288 |               15.0% of height |
| Bottom                    |    672 |               35.0% of height |

**Derived coordinates:** With a top-left origin, the allowed ad rectangle is `x = 48…888`, `y = 288…1248`, or `{ x: 48, y: 288, width: 840, height: 960 }`. The coordinates are arithmetic derived from the published margin labels. If represented as prohibited `safeZones` rather than an allowed rectangle, the complement is four non-overlapping bands: top `{x:0,y:0,width:1080,height:288}`, left `{x:0,y:288,width:48,height:960}`, right `{x:888,y:288,width:192,height:960}`, bottom `{x:0,y:1248,width:1080,height:672}`. The template says to keep _important_ creative elements inside the red area; it does not say backgrounds must stop there.

## Implications for Still Shift (inference)

1. **Keep platform profiles distinct.** A `vertical` output format can define 1080×1920, but an interface-overlay profile must also name its platform and placement. `youtube-shorts-organic` and `youtube-shorts-ad` should not silently share one numeric default. This follows from YouTube's variable creator guides and Google's separate ad guidance.
2. **Treat the ad rectangle as an opt-in conservative reference.** It is suitable for a Lab overlay and a user-selected ad-oriented lint profile. Applying it automatically to every organic Short would present an ad rule as though YouTube published it for creators.
3. **Preview the actual viewing surface before shipping.** The creator guidance is dynamic, and optional stickers, description length, device geometry and interface changes can move occlusion. A static rectangle can catch predictable risks, but it cannot prove that text is visible on every device. For final organic-Shorts acceptance, inspect a test upload in the current YouTube mobile feed and record the date and device used.
4. **Keep `safeInset` separate.** Its existing role is an authored layout margin. An interface-overlay `safeZone` should identify a named occluder or platform region and be enforced only when its profile is selected.

## Owner decision (2026-09-28)

The owner chose **organic YouTube Shorts first** and **no fixed numeric organic-Shorts safe-zone default**. Authors can configure named zones when a scene or viewing context calls for them. The Google Ads rectangle above remains an ad-specific research reference; it is not an automatic lint gate for organic Shorts. The [vertical video plan](vertical-video-plan.md#resolved-owner-decisions) records the related format, narration and batch choices.
