Queue creation consumes a strict `production-projects` declaration, capped at
300 projects and 1048576 bytes. Family/cue/QA paths resolve
from its file directory. It publishes one new immutable manifest and performs no
native capture. Run executes or resumes that pinned manifest through the existing
native queue, with bounded state/attempt rows and a linked complete state snapshot.
SIGINT/SIGTERM request durable cancellation. Exit codes are 0 for passed execution,
1 for terminal item failure, 2 for invalid input/command, and 130 for cancellation.
These are technical execution statuses; use report for artifact-specific QA.
Retry consumes an exact-CAS request capped at 32 selected terminal
items and 16384 bytes. Dependency pins must already be repaired. It
archives original/next manifests and grants one new batch on the selected items;
unchanged completed neighbors keep their products. The three-attempt/revision,
96-attempt/item and 32-revision bounds remain fixed. Retry performs no execution;
run consumes its authorization, retaining original failed attempts and reviews.

Queue creation defaults to `three-native`. Select `--backend blender-native`
with `--blender-executable /absolute/host/Blender` for native source/plan documents.
Run and report choose the backend from the pinned manifest version; an optional
`--backend` must agree. Blender version2 manifests require the same explicit host
executable/profile. Retry keeps either manifest version and executes no producer.
The Blender source policy is embedded-only; its receiver
uses verified sequences, native editable text and whole original audio. Source/control
tracks remain in Blender. Capture limits are 2000

8388608 pixels. Episode plans allow

1048576 bytes. These are candidate
technical lifecycle limits. Optional native `qaPath` declarations pin bounded

100000 aggregate comparisons and
2048 consecutive failure runs.
Actual retained Bpy observations supply numeric rules; reports bind raw findings,
grouped peaks and images to the current export. Bounds separation does not prove
surface contact/collision, and passed samples leave whole mechanical review open.
Native review evidence/handoff and whole pilot acceptance remain pending.
The handoff command retains its original Three.js scope.

The three-family native production profile is webgl2 with
raw_rgba transport. The three pack families remain
candidates. Operational QA replays original output-frame scalars and current cue timeline checks,
retains raw warnings and exact grouped peaks, and links immutable facts in reports and
handoffs. A custom QA plan is a pinned declarative dependency. State-lint admission is
2 MiB plus 4 KiB per generated layer-frame, capped by the published capacity and shared
Node allowance. Individual successful sampled rules do not grant whole mechanical
acceptance; current failures remain visible.

General imports and preview/export formats use existing episode
discovery. Review declarations, missing token data and pilot admission remain
separate from technical completion.

## Import, batch and rendering routes

Generated from the same scoped data exposed by episode and production discovery. Legacy episode protocol1 version fields retain their original meaning.

Automatic bridge overlap recovery uses `episode patch --recovery overlap` with current `--input`, `--prepared-dir`, `--final-output`, fresh `--output-dir` and `--cache-dir`. Its bounds are1 target,12 candidates,1 patch and1 export. It requires current measured target/qualification glyphs, retains the bad check and exact-CAS request, reuses every current clean plate and rechecks the final file. Unsupported/multiple targets or exhausted candidates leave source unchanged. Other final findings remain visible.

Rigid glTF/GLB import uses the Node API, without a glTF import CLI. The static triangle, rigid hierarchy, opaque core metallic/roughness and UV0 subset produces an intermediate asset. Native preview/export requires an authored mechanism-scene-3 plus separately verified hashed RGBA resources prepared through prepareRigidGltfPbr. Animation, skin, morph, sparse accessors, required extensions and remote resource fetching are excluded. Source bytes are capped at 33554432; dependencies at 33554432; image bytes at 8388608; texture pixels at 8388608. The complete report contains all import limits.

Image batch consumes JSONL image requests with concurrency1–2. It is not an episode composition queue. Production consumes at most 300 pinned family/cue projects with one serial worker and retained attempts.

Omitting the composition format retains legacy MP4 output. Profiled output dimensions are16–8192, with format-specific even-dimension requirements and lossless PNG/raw RGBA transport. Ordinary compositions accept1–4 workers; authenticated native observation delivery requires1. Higher-bit-depth profiles convert RGBA8 capture and do not establish higher-precision source capture.

Native composition preview/export shares prepared source/resource admission. Hardware preview appearance needs its own evidence. Episode preview returns one requested frame; episode export checks the whole final file. Cue capture stores png16 native plates, then exports MP4 overlays under the original picture/observation binding. Supported packs and whole pilot review remain separate.
