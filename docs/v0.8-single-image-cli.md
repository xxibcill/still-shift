# v0.8 single-image CLI evidence

`pnpm --silent still-shift animate` now calls `WebGLAnimationEngine`: validate request, prepare cached depth, resolve and safety-check a scene, export a validated MP4, then publish the scene manifest. The silent pnpm invocation keeps the result JSON alone on stdout. The no-op adapter remains available through `--adapter noop`. A normalization-only depth-worker command preserves the same source preprocessing when depth inference fails, allowing the shared renderer to export a 2D fallback without a depth image.

Verification on 2026-09-24:

- `pnpm test:browser:cli` passed a 16:9 explainer-style fixture through the real command. It produced 90 frames, reused depth on the second request, preserved source/depth/scene/output checksums, and handled depth failure with a valid 2D MP4 and stable warnings. Missing input and existing output returned machine-readable errors without partial files.
- The v0.1 no-op CLI integration suite still passes with `--adapter noop`.
- One private History Offstage S01E01 source still rendered through the same CLI with the pinned Depth Anything V2 Small cache: 150 frames, `horizontal_drift`, 1,955,079-byte MP4, no warnings, and 10.33 seconds end-to-end on this host. The local output and private source are not in version control. This is a technical candidate, not frozen-corpus acceptance.
- `pnpm build`, `pnpm lint`, and the full test command pass. The single-image command contract and exit codes are in [the CLI README](../tools/still-shift-cli/README.md).

The approved corpus and editorial review remain open. This version establishes a usable request and result contract for v0.9 batch orchestration.
