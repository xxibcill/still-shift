# v0.6 MP4 export evidence

The export worker uses the shared scene and WebGL renderer in pinned headless Chromium. It evaluates each frame by index at 30 FPS and streams it directly to FFmpeg. FFprobe checks dimensions, pixel format, frame rate, frame count, duration within one frame, and all BT.709 range/space/transfer/primaries fields; FFmpeg decodes the complete result before publication. The H.264 bitstream filter stamps BT.709 metadata where encoder defaults omit it. The worker writes a temporary MP4 in the destination directory and publishes by an atomic hard link, so an existing output is preserved and failures leave no partial final file.

Verification on 2026-09-24:

- `pnpm test:browser:export`: 90/90 frames at 320×180 for raw RGBA, in-memory PNG, and 95%-quality JPEG pipes; repeated PNG exports were byte-identical; a depth-preparation failure exported a 2D fallback with no depth image; missing input and existing-output cases left no partial files.
- Five seconds at 1920×1080: 150/150 frames, exact 5.000-second duration, H.264 `yuv420p`, full decode passed. A synthetic frame set exported in 29.8 seconds via raw RGBA and 4.1 seconds via PNG pipe. The two MP4 files were byte-identical.
- One private photographic candidate (source 2048×1143, output 1920×1080): PNG pipe took 9.44 seconds; JPEG pipe took 4.99 seconds. The JPEG result had mean SSIM 0.993 against the PNG result. These are single-scene measurements on this host, not a corpus-wide throughput claim.
- The host used Playwright 1.62.1 / Chromium 151.0.7922.34, FFmpeg 8.0.1, and SwiftShader WebGL. The optional VideoToolbox H.264 encoder produced a valid synthetic 150-frame MP4 but did not improve the raw-pipe wall time.

The PNG pipe is the default because it matches the raw output while avoiding the large raw upload bottleneck. The JPEG pipe is an optional speed experiment pending v0.7 visual parity and v0.10 editorial review. The real-image PNG result is below the 1× throughput target; the JPEG result only narrowly reaches it on one image. A representative throughput gate remains open.
