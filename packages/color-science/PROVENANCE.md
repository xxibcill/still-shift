# Provenance of `@still-shift/color-science`

Source audited: chroma-node (the owner's separate repository,
`~/Documents/guthib/chroma-node`, read-only) at commit
`b804dc0fb7473e5c8066e2c3e41cf16b6a2401f4`, file `src/shared/colorEngine.ts`.
chroma-node has no license file. **Owner decision 2 (2026-11-20, "Approve
both"):** code ported from it enters this repository under GPL-3.0-only, like
the rest of Still Shift.

Ported code is held to the same evidence as new code: every function below is
checked against the CG0 reference vectors
([`benchmarks/fixtures/color/cg0/vectors`](../../benchmarks/fixtures/color/cg0/README.md))
by `tests/unit/color-science.test.ts`. chroma-node's own functions were measured
against the same vectors before porting (CG1 results, `chromaNodeAudit`); a
function that failed was rewritten from its specification, not ported.

Not ported in CG1 (later milestones decide): qualifiers (ported in CG6) and power
windows (replaced by layer-mask windows in CG6), curves (piecewise linear there; CG4 uses splines), scope analysis (CG3),
frame analysis and solvers (CG10), the translation tracker (CG12), the GLSL
generator (the renderer owns GPU kernels), the profile registry, OCIO stub,
tone mapping and gamut compression (CG7/CG8, from published references).

Reference implementations used to produce the CG0 vectors (development only,
never runtime dependencies): colour-science 0.4.6 (BSD-3-Clause) and
OpenColorIO 2.4.2 (BSD-3-Clause). Constants were cross-checked against
colour-science; each function cites its published document in its source.
