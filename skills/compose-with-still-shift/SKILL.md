# Compose with Still Shift

Generated by `pnpm schema:generate`; edit `scripts/generate-composition-reference.ts` and the contract/registries to update it.

Select the runtime first. In a source checkout, work from its root with Node 22.23.1 and pnpm 10.29.3. The examples below use workspace imports such as `@still-shift/motion` and checkout `pnpm still-shift` commands.

In an npm project, use its installed, pinned `still-shift` package and lockfile, running from the project or its documented shared runtime directory. Public imports use `still-shift` for package APIs, `still-shift/motion` for the builder and `still-shift/motion/node` for Node asset helpers; replace the examples' workspace imports accordingly. Replace `pnpm still-shift` with `npx still-shift` using that local installation. Supply your own pinned art/fonts/media and project files; checkout fixture paths, galleries and `pnpm` scripts require a checkout. Read the installed README, CLI help and public exports for that version. Write a `.ts` program whose default export is a `composition-1` object, using the selected runtime's motion builder. Top-level await and an awaited default export work. The `comp` callback is synchronous: resolve Node assets before entering it.

```ts
import { comp, solid, seq, presets } from "@still-shift/motion";

export default comp({ width: 640, height: 360, fps: 24, frames: 96 }, (c) => {
  const bar = c.add(
    solid("bar", { size: [48, 160], color: "#D96A3B" })
      .at(296, 260)
      .anchor("bottom"),
  );
  c.marker("land", 24, { label: "Bar arrives" });
  c.timeline(
    seq(bar.scaleY.from(0).to(1, 24), presets.settle(bar, 20, { amount: 8 })),
  );
});
```

Use exactly one of `frames` or `seconds` for the composition duration. Allowed fps: integers from 1 through 60. Composition frame counts are positive integers; animation durations are nonnegative integers, and `{ seconds: n }` durations use `Math.round(n * fps)`. Markers use composition frames. Author keys before the composition's last boundary.

- Delivered layers: solid, image, depth-image, text, shape, group, null, precomp, adjustment, registered providers, camera, light, video, sequence and audio. Native shapes include cubic primitives/paths, four paints and all nine operators on Canvas/WebGL. Native xyz planes/cameras and bounded ambient/point/spot lights are implemented. Use WebGL2 for true perspective, depth displacement and lighting; Canvas supports affine camera moves. Plain builder `shape.rect` retains its solid-layer output; native authoring uses `shape.native(id,{contents:[...]})`.
- Layers added first are in front; later-added layers paint behind them. Put full-frame backdrop layers last, or use the composition background. For a delayed fade-in, start the layer at `.opacity(0)` (or gate visibility with `inPoint`); `.from(0)` sets the placed animation segment, rather than hiding an already-visible layer before that segment.
- Set transforms with `.at(x,y,z?)`, `.anchor("center" | "bottom" | ...)`, `.scale(x,y,z?)`, `.rotate(degrees)`, `.opacity(value)`, `.parent(layer)`, and native fields with `.with(options)`. Text without an explicit ID gets deterministic `text`, `text-2`, ... IDs.
- Add the actual layer object to `c` before animating it. Animate `.x`, `.y`, `.z`, `.position`, `.scaleX`, `.scaleY`, `.rotation`, `.alpha` or `.property(path)` via `.from(value).to(value,duration,easing)`, `.by(delta,duration,easing)` and `.keys([{frame,value,...}])`. `.opacity` is the static setter; `.alpha` is the animation property.
- Use `seq`, `par`, `stagger(motions,offset)`, `delay(duration,motion)`, `at("cue:id",motion)` and `after(referenceClip,offset,motion)`. A clip can be placed only once. Same-property key overlaps and conflicting boundary values fail; whole-vector and component tracks cannot be mixed.
- Timed layer fields are `inPoint`, `outPoint`, `startFrame` and `stretch`, set via `.with({ inPoint: 12, outPoint: 96 })`. In/out points gate visibility in composition frames, with an exclusive out point. Keys use local time `(scopeFrame - startFrame) / stretch`; timeline placement writes authored key times. For ordinary root cue-based timelines, keep the default `startFrame: 0` and use in/out points for visibility. Setting a layer's startFrame to the cue and also placing its animation with at(cue) offsets the animation twice.
- Local keyed/content time controls use `.with({ posterizeFps: 12 })` or `.with({ holdFrame: 7.5 })`. Hold wins; visibility and root-bound procedural clocks stay live. A precomp can set `loop: "cycle" | "pingpong"` and optional `loopCount` via `.with(...)`. Freeze keyed source content with one hold `timeRemap` key. These clock controls are configuration fields; read the reference for units, bounds and root-expression behavior.
- Motion recipes: `settle`, `press`, `recoil`, `handoff`, `breathe`, `drawOn`, `land`; call `presets.settle(layer,duration,{amount:8,property:"y"})` inside a timeline. These emit staged additive drivers/carriers. `drawOn` adds native trim keys to a shape layer and also supports the legacy `story.path@1.0.0` provider. Text recipes: `reveal`, `emphasize`, `correct`, `qualify`, `retype`, `count`, `redact`, `release`; `presets.text.emphasize(title,12,{manner:"highlight"})`. Correction requires `replacement`; qualification requires a smaller text layer and a `target` claim. Retype/count require two states; count also requires numeric states and a style with tabular figures. Presets need a positive duration ending within the composition.
- Pin images/fonts using `imageAsset` and `fontAsset` from `@still-shift/motion/node`, for example `await imageAsset("art","./art.svg",{relativeTo:import.meta.url})`. These read real bytes, dimensions and SHA-256. `image("hero",asset)` registers its image automatically; pass fonts in `comp({assets:[font],...})` and `text("Title",{fontAsset:font.id,...})`. For a repository-local font use `assets/story-motion/fonts/plex-sans-semibold.ttf` with weight `"600"`. Browser callers supply precomputed asset descriptors. Authored system fonts are errors; do not fabricate hashes.
- Native media builders are `video(id,asset,options)`, `sequence(id,asset,options)` and `audio(id,asset,options)`; a real precomputed descriptor registers automatically. Video/sequence descriptors pin original dimensions, reduced rational rate, frame count and supported SDR color; sequences pin an ordered PNG hash manifest. Audio pins actual decoded 48 kHz count/channels. Embedded video sound requires a separate audio asset. Media remap uses source seconds, precomp remap uses source frames. Use `frameBlending:"hold" | "linear"` for video/sequence; narration must preserve its authorized interval and inherited source clock. Read [native media](../../docs/composition-media.md) before authoring descriptors or clocks.
- Native mesh effects are `distort.mesh-warp` (2–8 row/column Bezier controls) and `distort.puppet` (alpha-outline mesh, rest/pins, starch and overlap regions). Add them through `.with({effects:[{id:"puppet",effect:"distort.puppet",params:{...}}]})`; keep material rest pins fixed and animate target pins via `.property("effects[puppet].pins[p5].y")`. Both backends implement these effects. For constrained prop following, use solved-position drivers and local pin coordinates. Read [puppet authoring](../../docs/story-acting.md#native-composition-puppet-acting) and [complete acting examples](../../examples/composition/12-puppet-acting/README.md); sweep every frame to catch mesh budget/pin/flip diagnostics.
- Native 3D layers set `.with({threeD:true})` and use xyz positions/scales, orientation and rotationX/Y through `.transform(...)`. A default camera uses the scope centre and z=-scope.width; `camera(id)` preserves that default until a position is authored. Optics use either zoom in pixels or focalLength/filmSize in millimetres; do not write both. Two-node POI is parent-space xyz. Depth runs preserve 2D barriers; projected precomps are flat surfaces with their own scoped camera. `coverage:"required"` validates actual alpha on every frame and shutter sample. Read the camera section before adding perspective group effects or constraints.
- Flat lighting requires WebGL2. Use `light(id,{lightType:"point",range:1000,intensity:1})` and explicitly 3D artwork with `.receiveLight()`. Ambient/point/spot controls are bounded; scope limits are eight lights including disabled ones. Default receiving is false; no active lights retains exact unlit pixels. Shading uses one two-sided geometric normal and linear diffuse RGB, preserving alpha before local effects/projection/focus. Precomp lights stay scoped; there are no cast shadows or inferred photo geometry. Read the bounded-lighting section for units and clock rules.
- Reused precomps are separate instances. Target instance paths such as `instance("left","child").path("x")`; nested definitions cannot silently carry root-only drivers/camera/expressions. Parent and matte references name layers in the same scope.
- Runtime expressions use the constrained text syntax via the expr tagged template, or `ref("left/child.x")`. Builder TypeScript runs once; arbitrary JavaScript does not run per frame. Read the linked generated reference for property paths, expression grammar, built-ins, masks/effects and diagnostics when needed.

```sh
pnpm still-shift comp validate --input program.ts
pnpm still-shift comp preview --input program.ts --watch
pnpm still-shift comp lint --input program.ts
pnpm still-shift comp export-json --input program.ts --output composition.json
pnpm still-shift comp bake --input program.ts --output baked.json
pnpm still-shift comp render --input program.ts --output clip.mp4
```

Explicit `comp render --format` profiles are `prores4444`, `png8`, `png16`, `h264`, `hevc10`, `prores422hq` and `vp9alpha`. Alpha survives in ProRes4444, PNG and VP9 alpha with a transparent root background; omit the format for the existing opaque MP4 path. PNG output needs a `%06d.png` filename pattern. `--workers 1|2|3|4` selects bounded parallel renderers; `--cache-static true|false` controls shared static reuse. Use PNG/raw transport for explicit profiles. Read [delivery details](../../docs/composition-reference.md#output-formats-and-parallel-rendering-ce15) for color, native-audio output and manifests. Programmable soundtrack routing/DSP is a separate [soundtrack-project workflow](../../docs/soundtrack-project.md) with its own optional runtime; native composition audio does not require that runtime.

Validate after authoring and fix located diagnostics before rendering. CLI accepts `.json`, `.ts`, `.mts` and `.cts`; JSON export rebases pinned asset paths to its output folder. Output writes refuse to overwrite existing files. Watch preview retains the last valid pixels/frame on an invalid rebuild. Lint reports motion craft separately from schema validity; use its findings to improve the clip. Verification runs locally using pnpm.
