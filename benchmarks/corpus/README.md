# Local corpus media

Place the 30–50 reviewed real explainer-workflow images here when their rights permit
local use. This directory is ignored by Git. Record every image in
`../corpus-manifest.json`, including project provenance, untracked/private paths,
dimensions, rights, and expected shot duration.

Do not mark the manifest `frozen` until all readiness checks pass and the review block
records who approved the corpus, when it was reviewed, and where the review evidence is
stored.
