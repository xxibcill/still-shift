# History Offstage style test fixtures

Three original, text-free 1920×1080 PNGs exercise motion treatments for an illustrated editorial style:

| Fixture                   | Intended motion test                                                             |
| ------------------------- | -------------------------------------------------------------------------------- |
| `tableau-hold.png`        | Locked hold or a short, small push on a broad three-band scene.                  |
| `system-panel-reveal.png` | Left-to-right reveal of three discrete system panels.                            |
| `split-comparison.png`    | Stepped reveal of the second panel while the divider and first panel stay fixed. |

These abstract images use the general Layered Chronicle palette and shallow graphic depth. They contain no episode sources, characters, text, dates, or historical claims. They are engineering fixtures only, not History Offstage production assets or Phase 0 corpus entries.

Regenerate with `python3 benchmarks/fixtures/history-offstage/make_fixtures.py` (requires Pillow). Do not substitute selected episode stills for these fixtures without following that episode's asset-treatment rules.
