# Editorial title fixtures (ET0)

Tracked reproductions of the editorial title findings from the
[2026-11-15 proof](../../../docs/editorial-typography-proof-2026-11-15.md), for
milestone ET0 of the
[editorial typography improvement plan](../../../docs/editorial-typography-improvement-plan.md).
Every input is tracked and license-free: a synthetic FFmpeg clip and the
repository's pinned OFL fonts. The fixtures are deliberate failure cases and
controls, not designs.

Exact measured values, render hashes and lint outcomes are recorded in
[`et0-baseline.json`](./et0-baseline.json). The milestone summary, including the
re-baseline of the proof on `main`, is in
[`docs/editorial-typography-et0-results.json`](../../../docs/editorial-typography-et0-results.json).

[`et6a-measure.ts`](./et6a-measure.ts) (ET6a) is not an ET0 baseline. It holds
the ET7a pilot's measurement failures on a plain paper frame (guessed widths,
a guessed highlight offset and a font-metric stack) as builders whose sizes,
origins and offsets are parameters, for
[`tests/browser/composition-text-measure.ts`](../../../tests/browser/composition-text-measure.ts):
each case renders once as the pilot placed it and once placed from
`comp measure`.

## Synthetic clip

[`media/editorial-bands.mp4`](./media/editorial-bands.mp4) (70,569 bytes,
1080×1920, 24 fps, 96 frames, BT.709 limited) is generated by FFmpeg 8.0.1
arithmetic only: a bright field (rows 0–899), a drifting mid-tone sinusoidal
texture (rows 900–1919) and a 220 px dark band moving down at 285 px/s. Its
descriptor and SHA-256 are in
[`media/editorial-bands.descriptor.json`](./media/editorial-bands.descriptor.json);
`comp validate` rejects any other bytes.

## Commands

Run from the repository root with the pinned toolchain (`pnpm toolchain:check`).

Regenerate the clip and confirm it is byte-identical to the committed one:

```bash
pnpm exec tsx scripts/editorial-titles/generate-fixture-clip.ts --check
```

Validate, render, lint and measure every fixture, and fail if any outcome or
render hash differs from the recorded baseline (about one minute; outputs go to
the git-ignored `benchmarks/results/editorial-titles-et0/`):

```bash
pnpm exec tsx scripts/editorial-titles/et0-baseline.ts --check
```

The recorded baseline is platform-specific: it was measured on macOS with the
pinned toolchain. Render hashes depend on the Chromium canvas and the host font
stack, and O5's hash and fallback ink count depend on whichever Thai fallback
face the host provides (that fallback is the O5 finding). On another platform,
expect `--check` to differ; record a separate baseline there rather than
treating the difference as a regression.

A milestone that intentionally changes one of these outcomes (for example ET1
rejecting `o5-plex-thai.ts`) re-records the baseline with `--write` and lists the
changed entries in its results file.
