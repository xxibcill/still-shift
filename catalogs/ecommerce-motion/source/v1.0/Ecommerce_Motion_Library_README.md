# E-commerce Motion Library

ไลบรารีสำหรับหาแนวทางและบรีฟ motion graphic ads จากภาพสินค้า โดยเน้นภาพนิ่งและ Product-in-hand

## ไฟล์ในชุด
- Ecommerce_Motion_Library.html: เปิดด้วยเบราว์เซอร์บนคอมพิวเตอร์ มีตัวกรอง รายการโปรด motion schematic และ brief ที่คัดลอกได้ ไม่ต้องติดตั้งหรือเชื่อมอินเทอร์เน็ตเพื่อใช้งานตัวไลบรารี
- Ecommerce_Motion_Library.xlsx: ตาราง 6 ชีต สำหรับวางแผนและแก้ไขรายละเอียด
- Ecommerce_Motion_Formats.csv: 40 formats สำหรับนำเข้าฐานข้อมูลอื่น
- library_data.json: เนื้อหาแบบ structured data

## เนื้อหา
40 working formats ใน 6 หมวด / 12 schematic motion demos / 8 storyboard recipes / 16 แหล่งอ้างอิงภายนอก
26 formats เริ่มจากภาพสินค้าเดียวได้ แต่บางแบบยังต้องตัดพื้นหลัง สร้างกราฟิก หรือเพิ่มข้อมูลจริง

## วิธีเริ่มจากภาพมือถือสินค้า
เปิด Formats แล้วเลือก Hand-held / Product-in-hand และ Asset ภาพเดียว
ลอง H01 Hand Cutout Reveal, H03 Hand Hero + Kinetic Headline, H04 Hand + Benefit Callouts หรือ H05 Hand + Price Tag Pop
เปิดรายละเอียดเพื่อตรวจ asset, Hook–Body–Close, ข้อควรระวัง และแก้ไข brief ก่อนคัดลอก
กด Motion Lab เพื่อศึกษาเทคนิค และ Ad Recipes เพื่อดูตัวอย่างลำดับเวลาสำหรับการบรีฟ
References เป็นลิงก์ภายนอก ต้องใช้อินเทอร์เน็ตเพื่อเปิด

## ขอบเขต
ชื่อ 40 รูปแบบเป็น working names ที่จัดขึ้นสำหรับไลบรารีนี้ ไม่ใช่ชื่อมาตรฐานจากแพลตฟอร์ม และไม่ใช่โฆษณาจริง 40 ชิ้นที่รวบรวมมา
Demos เป็นภาพเคลื่อนไหว CSS แบบ schematic ที่ทำขึ้นใหม่ แสดงเทคนิค ไม่ใช่ final ad, วิดีโอแบรนด์, MP4 หรือไฟล์ After Effects พร้อมใช้งาน
References แยกประเภท Template, Portfolio, Discovery และคู่มือเทคนิค พร้อมขอบเขตการตรวจแต่ละแหล่ง ตรวจชื่อและคำอธิบายที่เข้าถึงได้ ไม่ได้ยืนยันว่าได้ดู preview ทุกชิ้น
Related references มีไว้ศึกษาทิศทาง ไม่รับรองว่าทุกลิงก์แสดง storyboard ตรงตามสูตรทุกขั้นตอน
เวลาคลิปและความซับซ้อนเป็นจุดเริ่มต้นที่เสนอ ไม่ใช่ข้อกำหนดแพลตฟอร์ม และไม่มีการรับรองผลยอดขาย
อย่าใช้ภาพเดียวสร้างมุมสินค้าที่ไม่มีข้อมูลอ้างอิง โดยเฉพาะมุมด้านหลัง ชิ้นส่วนภายใน หรือการหมุน 360 องศา
ส่วนลด รีวิว สถิติ before/after และนโยบายร้าน ต้องใช้ข้อมูลจริงที่ได้รับอนุญาต
ไฟล์/เพลง/ฟอนต์/ภาพจากแหล่งภายนอกไม่ได้รวมมาในชุดนี้ ต้องตรวจสิทธิ์และเงื่อนไขก่อนใช้งาน
รายการโปรดถูกเก็บในเบราว์เซอร์ของเครื่อง หากเบราว์เซอร์จำกัดการจัดเก็บไฟล์ local จะเก็บได้เฉพาะ session
